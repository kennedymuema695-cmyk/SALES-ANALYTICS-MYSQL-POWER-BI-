📊 Sales Analytics Project | MySQL & Power BI

Project Overview

This is an end-to-end Sales Analytics project using MySQL for data exploration and analysis (EDA) and Microsoft Power BI for interactive dashboard development.

The objective is to transform raw sales data into meaningful business insights that support data-driven decision-making.

🛠️ Tools & Technologies

- MySQL – Data exploration and analysis
- Microsoft Power BI – Data visualization and dashboard development
- SQL – Data aggregation and business analysis

📁 Project Structure

MySQL/

- "sales_eda.sql" – SQL queries for exploratory data analysis.

PowerBI/

- "Sales-analytics project.pbix" – Interactive Power BI dashboard.
- Dashboard screenshot – Visual representation of the analysis.

🔍 Key Business Insights

- Bikes contributed 72.45% of total revenue.
- Accessories recorded the highest profit margin of 58.62%.
- The United States generated the highest revenue of 28M.
- Canada achieved a profit margin of 46.84%.
- Adults generated the highest revenue of 43M.

💡 Business Recommendations

- Increase investment in high-margin product categories.
- Explore opportunities in high-profit geographical markets.
- Improve customer retention strategies.
- Optimise product inventory based on sales and profitability.

🎯 Conclusion

This project demonstrates how MySQL and Power BI can work together to transform raw sales data into actionable business insights.
